# Rahul M. S & Aditya M Wedding Invitation

A responsive, static digital wedding invitation inspired by the supplied lavender, ivory, watercolour-floral invitation card.

## Run locally

Open `index.html` in any modern browser. No build process or server is needed.

## Personalise

Edit the clearly marked `weddingConfig` object at the top of `script.js` for event details, date, and Google Maps URLs.

Place optional assets in these paths:

- `assets/couple.png` - supplied couple image (included)
- `assets/music.mp3` - optional background music
- `assets/marriage-qr.png` and `assets/reception-qr.png` - optional genuine QR images
- `assets/gallery/photo1.jpg` through `photo6.jpg` - optional gallery images

Missing optional images are rendered as elegant placeholders. The site uses only relative paths, so it is ready to deploy on GitHub Pages: push this folder to a repository, then enable Pages from the branch root.
